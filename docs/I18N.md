# i18n — Passandi

## Aturan

- Semua string user-facing wajib pakai `t()` dari `useTranslation()`
- Tambah string baru ke **kedua** locale files sekaligus

```tsx
const { t } = useTranslation();

// ✅
<Text>{t("auth.login")}</Text>

// ❌
<Text>Masuk ke Akun</Text>
```
