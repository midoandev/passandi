Passandi adalah aplikasi password manager mobile yang mengutamakan keamanan dan kemudahan penggunaan.

## Fitur Utama

- 🔐 Brankas terenkripsi AES-256-CBC
- 📱 Local First — offline tanpa internet
- 🔢 PIN 6 digit & Biometrik (Face ID / Fingerprint)
- 🗂️ Kategori custom dengan drag-to-reorder
- 🌙 Dark / Light mode
- 🌐 Multi bahasa (Indonesia & English)
- 🔄 Auto cloud sync
- 📋 Password generator

## Tech Stack

| Layer | Teknologi |
|---|---|
| Framework | Expo SDK 56 + React Native 0.85 |
| Language | TypeScript |
| Navigation | Expo Router v3 |
| State | Zustand + TanStack Query |
| Database | expo-sqlite |
| Encryption | AES-256-CBC |
| Backend | Supabase (Auth + PostgreSQL) |
| Analytics | PostHog |
| Crash | Sentry |
