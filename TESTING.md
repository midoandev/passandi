# Testing Documentation

Dokumentasi ini menjelaskan cara menjalankan unit tests untuk aplikasi Passandi.

## Setup Testing

Testing dependencies yang digunakan:
- **Jest** - Test runner
- **@testing-library/react-native** - React Native testing utilities
- **@testing-library/jest-native** - Custom matchers untuk React Native

## Instalasi Dependencies

Sebelum menjalankan test, install testing dependencies dengan 2 langkah:

**Step 1: Install React Native Jest Preset**
```bash
npm install --save-dev @react-native/jest-preset --legacy-peer-deps
```

**Step 2: Install Testing Libraries**

**PENTING:** Karena aplikasi menggunakan React 19.2.3, gunakan flag `--legacy-peer-deps` untuk mengatasi peer dependency conflict:

```bash
npm install --save-dev jest@^29.7.0 @testing-library/react-native@^12.4.0 @testing-library/jest-native@^5.4.3 --legacy-peer-deps
```

Lihat [INSTALL_TEST_DEPS.md](./INSTALL_TEST_DEPS.md) untuk alternative installation methods.

## Menjalankan Tests

### Run Semua Tests
```bash
npm test
```

### Run Tests dalam Watch Mode
```bash
npm run test:watch
```

### Run Tests dengan Coverage Report
```bash
npm run test:coverage
```

### Run Specific Test File
```bash
npx jest path/to/test/file.test.ts
```

### Run Tests yang Match Pattern
```bash
npx jest -t "test name pattern"
```

## Best Practices

1. **Isolate Tests**: Setiap test harus independen dan tidak bergantung pada test lain
2. **Clear Mocks**: Gunakan `jest.clearAllMocks()` di `beforeEach()`
3. **Reset State**: Reset store state di `beforeEach()` untuk Zustand stores
4. **Mock External Dependencies**: Mock semua external dependencies (Supabase, Expo modules)
5. **Test Behavior, Not Implementation**: Focus pada behavior user, bukan implementation details

## Troubleshooting

### Tests Tidak Jalan
1. Pastikan dependencies sudah terinstall
2. Clear Jest cache: `npx jest --clearCache`
3. Check Jest configuration di `jest.config.js`

### Mock Errors
1. Pastikan mocks didefinisikan sebelum import
2. Check mock path sesuai dengan actual module path
3. Verify mock implementation returns expected values

### TypeScript Errors
1. Check `@types/jest` sudah terinstall
2. Verify tsconfig includes test files
3. Use type assertions jika perlu: `as jest.Mock`
